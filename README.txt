MyLibrary Website Prototype — Milestone 1

HOW TO RUN
1. Extract the ZIP file.
2. Open the MyLibrary folder in Visual Studio Code.
3. Open index.html using Live Server (recommended), or open it in a browser.

CURRENTLY WORKING
- Responsive homepage layout
- English, Hindi and Kannada interface text for the main navigation and hero/catalogue headings
- Sample book catalogue
- Search by title, author, category or sample ISBN
- Category and availability filters
- Clear filters button
- Mobile navigation menu
- Dark mode toggle
- Voice search where the browser supports Web Speech Recognition

IMPORTANT LIMITATIONS
- Book records and availability are sample/demo data, not connected to Bantwal Public Library.
- Login, membership, requests, reservations, AI assistant, notifications, QR membership, real ISBN lookup, backend, database and Android app are not implemented yet.
- Voice recognition support varies by browser and device. It may require HTTPS or localhost.
- Hindi/Kannada interface translation currently covers the main navigation and homepage/catalogue headings only.

NEXT MILESTONE
Confirm the real catalogue fields and library workflow, then build the backend/database and connect the book catalogue.
